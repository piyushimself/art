Networking Practical File

Ten hands-on projects, built at home, for a complete beginner. One project per week, about 5 to 6 hours each. Tick each step as you finish it and your progress is saved in this browser.

0%

What you need

  • A laptop (Windows, macOS or Linux) and access to your home router
  • Python 3, Wireshark, VirtualBox, Cisco Packet Tracer (free account), Nmap
  • A notebook or a text file for your lab record

Install Python packages once: pip install dnspython

Safety rules

  • Scan, sniff and test only your own devices and your own home network.
  • Never capture traffic on a network you do not own, such as a café or office.
  • Before changing router settings, write down the old value so you can undo it.

How to write each experiment

For every project record five things: aim, tools, steps you did, output (screenshot or text), and what broke and how you fixed it. Then answer the viva questions without looking.
